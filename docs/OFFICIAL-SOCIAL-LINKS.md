# Official artist links

The artist directory displays compact, accessible platform icons, with full names in tooltips and screen-reader labels. YouTube destinations come from resolved official channels; unavailable identities are omitted. Reviewed social links live in each group bundle's `officialLinks` list, with `platform`, `url`, `evidenceUrl`, and `checkedAt`. Missing links are not guessed from artist slugs. These are outbound shortcuts, not non-YouTube content collectors.

Supported destinations: YouTube, Weverse, Berriz, X/Twitter, Instagram, TikTok and artist websites. Use HTTPS and the matching platform domain. Add verified URLs to the group bundle; validation, catalog publication and directory rendering handle them automatically. Multiple official accounts may be stored with an optional `label`.
