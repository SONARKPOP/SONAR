# 표시 유형·금지·예외 허용

## 표시할 유형

LIVE NOW 위의 여자 / 남자 / 혼성 / 듀오·솔로 버튼으로 화면에 표시할 유형을 고릅니다. 여러 유형을 함께 켤 수 있으며 마지막 하나는 끌 수 없습니다. 설정은 새로고침 후에도 유지합니다.

꺼진 유형은 LIVE NOW, MY GROUPS와 영상 목록에서 숨깁니다. 저장한 MY GROUPS와 선호 목록은 삭제하지 않으므로 유형을 다시 켜면 기존 선택이 돌아옵니다. 그룹 편집 창에서는 숨긴 유형도 찾아서 관리할 수 있습니다. 듀오·솔로 분류는 성별보다 우선하므로 AKMU는 혼성 그룹 버튼과 중복 적용되지 않습니다.

## 편집 창

MY GROUPS → 편집에서 그룹 줄을 눌러 목록에 추가·제거합니다. 그룹 아래 하트·별·새싹은 해당 선호 목록을 각각 지정·해제합니다. 금지 아이콘은 개별 금지, 방패 아이콘은 예외 허용입니다. 변경은 누르는 즉시 반영·저장하며 적용 버튼은 없습니다.

**하트·별·새싹 중 하나라도 지정된 그룹은 항상 자동 예외 허용입니다.** 금지 버튼이 비활성화되고 자동 허용을 끌 수 없습니다. 선호를 모두 해제하면 자동 보호가 끝나며, 별도 수동 예외 설정은 유지합니다. 유형 전체를 금지해도 선호는 삭제하지 않습니다.

## 제외 설정

보기 설정 → 제외 설정에서 유형 전체 금지와 개별 금지, 예외 허용을 확인할 수 있습니다. 같은 조작은 편집 창의 각 그룹에서도 가능합니다.

최종 판정 순서는 **선호그룹 자동 예외 → 수동 예외 허용 → 개별 금지 또는 유형 금지**입니다. 예외가 금지보다 우선합니다. 이전 버전의 ‘개별 금지 우선’ 정책은 사용자 요청으로 폐기했습니다.

선호가 없는 그룹을 개별 금지하면 수동 예외는 해제됩니다. 수동 예외를 켜면 개별 금지는 해제됩니다. 선호를 새로 지정할 때도 개별 금지를 해제합니다. 기존 저장 값에 금지·예외가 겹쳐 있어도 예외가 우선합니다.

유형 전체 금지, 개별 금지, 수동 예외는 서로 다른 목록으로 저장합니다. 유형 전체 금지가 켜진 유형에 새 아티스트가 추가되어도 같은 정책을 적용하며 선호·예외는 보호합니다. 유형 표시 버튼을 끈 것은 금지 목록에 등록하는 것과 다릅니다.

## 저장 키

- 표시 유형: sonar.enabled-artist-types.v1
- 유형 전체 금지: sonar.blocked-artist-types.v1
- 개별 금지: sonar.excluded-groups.v1
- 수동 예외: sonar.allowed-groups.v1
- 자동 예외는 하트·별·새싹 목록의 합집합에서 계산하며 별도 수동 목록에 복사하지 않습니다.

## JSON 로딩 보완

미리보기의 JSON을 파일 내부에서 직접 읽고, 수집 대기 아티스트의 빈 인덱스 요청은 생략합니다. HTML이 반환되면 해당 파일명을 포함한 안내를 표시합니다. 상세 메타데이터 한 건의 오류가 영상 목록 전체를 지우지 않도록 했습니다. 최초 오류의 주소는 제공되지 않아 원래 실행 환경을 특정하지는 못했습니다.
