# 분석 확장 기준

FAMD를 기본 보기로 한다. PCA는 수치 변수 비교용으로 유지한다. 소속사와 레이블은 분리하며 현재 소속을 범주 변수로 사용하고 이전 소속은 프로필 이력에 보존한다. 모회사와 운영 레이블을 동일 회사로 합치지 않는다.

추가 후보는 현재 나이의 편차, 정확한 데뷔일과 당시 소속이 확인된 멤버의 데뷔 평균 나이, 솔로 활동 멤버 비율, 이전 멤버 비율, 국적 구성, 활동기간이다. 해당 분모와 출처가 확인되고 관측률 기준을 만족하는 경우에만 추가한다. 멤버 정보가 일부뿐인 그룹의 잔류율·국적 비율을 완전한 관측으로 처리하지 않는다.

콘텐츠 유형 비율, 제작진 다양성, 자체 작사·작곡 비율은 전체 수집 범위를 확인하기 전에는 결측으로 유지한다. 타이틀곡 일부만 등록된 상태를 전체 음반 경력으로 해석하지 않는다. 범주 수준이 지나치게 많거나 표본이 적은 소속사·레이블은 기존 전처리 규칙에 따라 제외하고 이유를 표시한다.

재분석은 `node scripts/analysis-features.mjs`, `python -m collectors.multivariate --input public/data/analysis-features.json --output public/data/multivariate.json` 순서로 실행한다. 기준일·난수 시드·결측 처리 정책은 기존 결과에 기록한다.
