# 비공개 개선 의견

Google Forms의 응답용 주소(`/viewform` 또는 `forms.gle`)를 `config/feedback.json`의 `responseUrl`에 설정한다. 편집 주소나 응답 시트 주소는 공개 코드에 넣지 않는다. 연결 전에는 사이드바 버튼이 비활성화된다.

권장 질문: 개선 의견(필수 장문), 관련 화면(선택), 문제가 발생한 기기(선택). 이름·이메일은 필수로 요구하지 않는다. Google Forms 설정에서 결과 요약 보기와 응답 공개를 끄고, 편집자·연결 시트 공유 대상을 소유자로 제한한다. 실제 공개 여부는 폼 소유자가 설정에서 확인해야 한다.

## 관리자 화면

현재는 Google Forms/응답 시트의 소유자 화면을 사용하는 방식을 권장한다. 별도 관리자 페이지는 대규모 검수·분류·감사 이력이 필요해질 때 도입한다. 공개 GitHub Pages에서 숨겨진 URL이나 프런트엔드 암호만으로 관리자 보안을 구현하지 않는다. 향후 구현 시 서버 인증·역할 권한·비공개 저장소·감사 로그가 필요하다. API 키와 응답 원문은 공개 JSON이나 localStorage에 저장하지 않는다.
