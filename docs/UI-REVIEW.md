# SONAR UI 점검

## 적용한 구성

왼쪽: 브랜드 → 검색·주야간 → 언어 → LIVE NOW → MY GROUPS. 본문: 비공식 팬페이지 안내 → 콘텐츠 탭 → 목록 제목 → 접힌 필터 → 영상. 이전 최상단 헤더를 제거해 영상 영역을 앞당겼습니다. 접은 사이드바에서도 검색 아이콘과 주야간 버튼을 사용할 수 있습니다. 검색 아이콘은 사이드바를 펼치고 입력창으로 이동합니다. 모바일 검색은 메뉴 안에 있으며 Enter를 누르면 메뉴를 닫습니다.

본문과 index.html의 제목·설명에 ‘비공식 K-POP 팬페이지’를 명시했습니다. 하단은 ‘SONAR ON’으로 변경했습니다.

## 발견하고 수정한 점

| 항목 | 불편/원인 | 반영 |
| --- | --- | --- |
| 상단 정보 중복 | 헤더와 목록 설명이 영상 위 공간을 차지함 | 헤더 제거, 팬페이지 안내 한 줄로 축소 |
| 여러 선호 프리셋의 카드 색상 | 마지막 선택 프리셋만 색상 판정에 사용 | 세 프리셋 합집합으로 선호 카드 판정 |
| 아무 그룹도 체크하지 않은 화면 | ‘조건에 맞는 영상 없음’만 표시해 원인 불명확 | 그룹 선택 안내와 그룹 추가 버튼 제공 |
| 선택 그룹 이름이 긴 경우 | 줄바꿈으로 필터와 영상이 아래로 이동 | 한 줄 말줄임 |
| 사이드바 접기 | 이동된 검색 입력창이 좁은 바에 들어가지 않음 | 검색 아이콘으로 대체하고 펼친 뒤 입력 |

## 다음으로 권하는 개선

1. **그룹 줄 조작 간소화:** 이름 앞 선호 아이콘 3개, 체크, 삭제가 한 줄에 있어 작은 화면에서 누르기 어렵습니다. 모바일에서는 이름·체크를 주 조작으로 두고 선호·삭제는 펼친 관리 영역으로 옮기는 방식을 권합니다. 현재 사용자 지정 조작은 유지했습니다.
2. **전체 조작의 의미 구분:** All은 제외 그룹을 뺀 전체 목록, 전체 켜기/끄기는 현재 목록 체크, 전체 그룹 제거는 목록 비우기입니다. 상호 차이가 커서 All을 ‘전체 목록’으로 표시하거나 설명을 붙이는 것이 좋습니다. 현재 명칭과 동작은 유지했습니다.
3. **외부 콘텐츠 실데이터 확보:** 현재 공식 영상 90개만 있으므로 외부 탭은 비어 있습니다. 디자인 문제가 아닌 데이터 범위 문제입니다. 출연 확인을 거친 외부 영상을 추가해야 분류 탐색을 실제로 평가할 수 있습니다.
4. **작은 보조 글자:** 그룹·날짜·태그의 일부 글자가 작습니다. 다음에는 실제 스마트폰에서 가독성을 확인하고, 영상 제목보다 우선순위가 낮은 정보를 줄이는 방식으로 여백을 확보하는 편이 좋습니다.

## 확인 범위

현재 소스·스타일·데이터 구조를 기준으로 검토했습니다. 프로덕션 빌드와 JavaScript 검사를 수행하지만 실제 브라우저의 화면·터치·키보드 시각 검사는 이번 작업에서 수행하지 않았습니다. 따라서 겹침이나 실제 기기 가독성이 없다고 단정하지 않습니다. 새로운 API 수집이나 GitHub 배포는 수행하지 않았습니다.

후속 반영: MY GROUPS 기본 보기와 편집을 분리했습니다. 전체 행 선택과 선호 배지를 기본으로 표시하고 관리 버튼은 편집 시에만 나타납니다. All은 전체 버튼으로 표시하며 재클릭해도 그룹 목록을 보존합니다.
