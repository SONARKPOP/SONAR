# 멤버 태그 원칙

[SCENE-FLIX 공개 코드](https://github.com/Adam-yam/SCENE-FLIX/blob/main/index.html)에서 확인한 라이브 분류는 영상별 `members` 목록과 `memberMatch` 필터를 사용합니다. `전원`이 명시된 영상은 각 멤버 필터에도 포함합니다. 이 부분의 코드만으로 해당 목록이 전부 수작업인지, 별도 도구로 생성했는지까지 확정할 수 없습니다. 자동 얼굴 인식이나 출연 확인 알고리즘이 있다는 근거로 해석하지 않습니다.

SONAR는 이처럼 영상에 멤버 ID 목록을 연결하되 여러 그룹을 지원하므로 이름 대신 `group-member` 고유 ID를 사용합니다. 다른 사이트의 영상별 멤버 목록을 복사하거나, 그룹 공식 영상이라는 이유로 전원 태그를 붙이지 않습니다.

- 제목에 명시된 이름을 우선합니다. 설명란의 전원 명단은 출연 근거로 사용하지 않습니다.
- 영어 일반 단어와 겹치는 이름, 그룹 사이 동명이인은 그룹 맥락과 명확한 표기가 필요합니다.
- 직접 확인한 영상은 `config/overrides.json`의 해당 YouTube 영상 ID 아래 `memberIds` 배열로 등록합니다. 이 배열은 자동 추론보다 우선하며 빈 배열은 잘못된 자동 태그를 제거합니다.
- 전원 출연을 직접 확인한 경우에만 해당 그룹의 실제 멤버 ID들을 모두 기입합니다. 그룹명만 보고 자동으로 전원으로 변환하지 않습니다.
- 라이브 탭 위쪽에 확인된 멤버 태그를 표시하고, 카드에도 해당 멤버를 표시합니다. 확인할 수 없는 영상은 `미분류`입니다.
- `memberTagging`은 자동/수동 태그 근거를 기록하지만 현재 시스템은 영상을 직접 시청했다는 검증을 주장하지 않습니다.

설정한 실제 태그를 적용하려면 기존 영상 수집·검수 갱신을 실행합니다. 영상 ID와 멤버 ID가 현재 그룹 관계에 맞지 않으면 수집기가 오류를 냅니다. 얼굴 인식과 자동 자막 판정은 구현하지 않았습니다.
