# 기간·라이브·외부 콘텐츠

## 화면

- 연도와 월을 각각 선택합니다. 전체 연도에서 월만 고르면 모든 연도의 해당 월을 표시합니다. 날짜는 업로드 시각을 한국 시간으로 환산합니다. 다른 필터와 AND로 결합하며 변경 시 첫 페이지로 돌아갑니다.
- 라이브 영상 탭은 `format: live`인 방송 영상 아카이브입니다. 왼쪽 LIVE NOW는 공식 채널의 실제 진행 중 방송만 표시하는 별도 기능입니다. 과거 라이브 여부는 API의 실제 방송 정보로 판단하며 제목만으로 추측하지 않습니다.
- 외부 콘텐츠는 노래·퍼포먼스, 라디오, 예능, 인터뷰, 광고·홍보, 기타·미분류 → 프로그램/채널 순서로 탐색합니다. 공통 출연 그룹이 많은 프로그램/채널이 먼저 표시됩니다.
- 주간은 밝은 회청색 버튼, 야간은 어두운 청색 버튼을 사용하며 활성 탭의 배경·테두리·밑줄을 강조합니다.

## 외부 콘텐츠 편집

공개 데이터가 없는 프로그램을 샘플 영상으로 채우지 않습니다. 실제 외부 영상이 수집되면 채널 항목이 나타납니다. `config/overrides.json`의 영상 ID 아래에 다음 필드를 지정할 수 있습니다.

```json
{
  "category": "external",
  "externalType": "interview",
  "programId": "verified-show-slug",
  "programName": "확인한 프로그램명"
}
```

이는 형식 설명이며 실제 프로그램 등록값이 아닙니다. `externalType` 값은 `song`, `radio`, `variety`, `interview`, `ad`, `other`입니다. 명시한 분류가 우선하며, 없는 경우 제목·태그의 명확한 단서를 사용합니다. 근거가 없으면 미분류로 둡니다. 프로그램 ID가 없으면 업로드 채널로 묶습니다. 멤버는 기존의 보수적인 제목/수동 태그 정책을 유지합니다.


외부 행사 일정 수집은 제거했습니다. 업로드 달력은 유튜브 게시일을 한국 시간으로 나눈 날짜별 그룹 요약입니다. LIVE·Shorts·롱폼 아이콘에 개수를 표시하며 눌러서 영상 목록을 펼칩니다. 롱폼은 자체·외부 태그가 있는 일반 영상입니다.

자체 콘텐츠는 `ownType`: `behind`, `daily`, `variety`, `practice`, `other`의 큰 분류만 사용합니다. `contentTypes`에 `own`, `external`을 중복 지정할 수 있습니다. 프로그램 이름은 검색/메타데이터로 유지하며 자체 콘텐츠의 시리즈별 버튼을 계속 늘리지 않습니다.

언어는 KR·JP·EN·ES의 주요 UI 문구를 제공하며 영상·그룹 이름은 원문을 유지합니다. 데스크톱 사이드바 접기 상태와 언어는 로컬에 저장합니다.
